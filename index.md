      <p class="eyebrow">Remote access and security</p>

      <h2>Remote control shouldn’t mean exposed equipment.</h2>

      <p>
        Blinky-Lite uses publish-subscribe messaging, with devices
        initiating connections from inside the facility. Role-based
        permissions help control access to applications and data.
      </p>

      <p>
        This is part of a layered approach. Security also depends on
        network protection, authentication, configuration and ongoing
        operation.
      </p>

      <a class="text-link"
         href="{{ '/blinky-lite/' | relative_url }}#security">
        Learn about the architecture →
      </a>
    </div>
